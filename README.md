# Calorie Math

Daily calorie needs (Mifflin-St Jeor BMR and TDEE), calories from macros, protein RDA and a Markdown Nutrition Facts table, from the Sublime Text command palette.

Commands: `Calorie Math: Daily Calories (TDEE)`, `Calorie Math: Calories From Macros`, `Calorie Math: Insert Nutrition Facts Table`.

Estimates for general wellness, not medical advice. Web calculators with the same formulas: https://snowbelly.app/tools/calorie-calculator/
